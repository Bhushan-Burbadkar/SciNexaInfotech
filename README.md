# SciNEXA Infotech website

Static HTML / CSS / JS site (no build step) hosted on GitHub Pages.

```
index.html + 14 module pages (APQR, CPV, CVS, eQMS, dms, LMS, LIMS, Stability, QCPlanning, eBMR, eLogbook, CAPS, UAM, RIMS)
css/styles.css   Styles
js/script.js     Menu, animations, contact form (Formspree)
images/          Logos, photos, client logos, module slides
.nojekyll        Tells GitHub Pages to serve files as-is
```

## Contact form (Formspree)
In `index.html`, replace `YOUR_FORM_ID` in the form `action` with your Formspree form ID.
